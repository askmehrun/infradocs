# Security Policy

## Reporting Security Vulnerabilities

If you discover a security vulnerability in InfraDocs documentation or templates, please report it responsibly.

## Security Considerations

- Never commit real infrastructure IPs, credentials, or sensitive configuration
- Use RFC 5737 documentation ranges for IP examples (`192.0.2.0/24`, `198.51.100.0/24`)
- Review content before committing to ensure no sensitive data is exposed
- This is a documentation template — sanitize all real-world details before deployment
