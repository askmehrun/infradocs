Infrastructure architecture documentation.

This section contains high-level architecture decisions and diagrams for network, compute, storage, and service topology.

**Use this section for:** architecture overviews, network topology, compute layout, storage layout, service dependency maps.

**Do not use this section for:** individual server inventories (use Infrastructure), operational procedures (use Operations or Runbooks), or platform configuration (use Platforms).

**Archetype:** `infrastructure` for architecture components, `default` for general architecture pages.

**Relates to:** Infrastructure (physical components), Platforms (runtime environment), Services (service dependencies).
