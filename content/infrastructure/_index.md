Physical and virtual infrastructure components.

This section contains documentation for compute, network, storage, and facilities resources.

**Use this section for:** compute hosts, network devices, storage systems, facilities and data centers.

**Do not use this section for:** architecture diagrams (use Architecture), platform configuration (use Platforms), service definitions (use Services).

**Archetype:** `infrastructure` for infrastructure components, `default` for general pages.

**Relates to:** Architecture (logical design), Platforms (virtualization layer on top), Services (services running on infrastructure).
