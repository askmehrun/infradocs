Documentation of the platforms that run infrastructure.

This section contains documentation for virtualization, operating systems, containers, networking, storage, endpoint management, and observability platforms.

**Use this section for:** hypervisors, OS images, container orchestration, network switches, storage arrays, endpoint management, observability tooling.

**Do not use this section for:** physical hardware inventories (use Infrastructure), service definitions (use Services), operational procedures (use Operations or Runbooks).

**Archetype:** `platform` for platform components, `default` for general pages.

**Relates to:** Infrastructure (runs on top), Services (services deployed to platforms).
