Architecture Decision Records (ADRs) capture significant architectural decisions.

This section contains ADRs documenting the context, decision, and consequences of significant architecture choices.

**Use this section for:** ADRs for network design, compute choices, storage decisions, platform selection, service architecture.

**Do not use this section for:** operational procedures (use Operations), runbooks (use Runbooks), service definitions (use Services).

**Archetype:** `adr` for all decision records.

**Relates to:** Architecture (ADRs document architecture decisions), Standards (ADRs may reference standards), Platforms (platform selection ADRs).

## ADR Template

Use the `adr` archetype to create new decision records:

```
hugo new decisions/0002-example-decision.md --kind adr
```
