Infrastructure services documentation.

This section contains documentation for shared infrastructure services.

**Use this section for:** DNS, DHCP, identity, monitoring, backup, and software deployment service definitions.

**Do not use this section for:** individual server inventories (use Infrastructure), operational procedures (use Operations or Runbooks), platform configuration (use Platforms).

**Archetype:** `service` for service definitions, `default` for general pages.

**Relates to:** Infrastructure (services run on infrastructure), Platforms (services deployed to platforms), Operations (services are monitored and operated).
